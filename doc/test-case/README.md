# 测试用例文档

可判定通过/失败的行为契约。协议见 [全局设计](../global-design.md)，`ErrorCode` 见 `app/src/lib/utils/errors/constant.ts`。

## 目录

| 文件 | 用途 |
|------|------|
| `README.md` | 本约定 |
| `example.test.md` | 单条模板 |
| `{模块}/{模块}.{层次}.test.md` | 用例集，层次为 `unit` / `http` / `ui` |

用例集文首：**环境**（Base、路径、种子、隔离、未落地范围）、**覆盖清单**、**执行清单**。按资源拆文件；增删 TC 同步两张清单。

文件层次 = 调用面；用例「层级」= 契约落点（`Parse` / `Service` / `HTTP` / `UI`）。`*.http` 可收录 Parse/Service，步骤仍写 HTTP。同一 Zod 规则不必再开 `unit`。

## 命名

`TC-{域}-{资源}-{动作}-{序号}`，序号按动作从 001 递增。动作取 HTTP 方法，或 `GETID` / `SCENE`。标题：`动作·条件`。

例：`TC-API-V1-POST-001 创建测试项·合法入参`

## 用例字段

| 字段 | 说明 |
|------|------|
| 目标 | 一句话契约 |
| 前置 | 无则写「无」 |
| 层级 | `Parse` / `Service` / `HTTP` / `UI` |
| 方法 | 等价类、边界值、场景法、错误猜测、状态迁移、决策表（可多选） |
| 步骤 | HTTP：方法、路径、headers、body/query |
| 期望 | 具体状态码、`ApiResult` 关键字段、副作用 |
| 关联 | Schema / Service / 设计锚点 |
| 优先级 | `P0` / `P1` / `P2` |

失败必须写 HTTP 状态与 `error.code`。不写实现、不写工具步骤。

## 协议

成功：HTTP 写本入口实际码 + `{ success: true, data, timestamp }`。  
失败：HTTP = `AppError.statusCode` + `{ success: false, error: { code, message, details? }, timestamp }`。  
`code` 是短语（`"Not Found"`），不是资源级码。未落地的码不进分母。500 默认不进 P0；若测只断言信封。

## 取材

1. Schema：形状、边界、默认值  
2. Service：冲突、不存在、状态变化  
3. 协议：`ApiResult`、`parse*` / `apiHandler`

## 选法与优先级

先定层级，再定风险，最后选方法。

| 层级 | 优先方法 |
|------|----------|
| Parse | 等价类、边界值 |
| Service | 等价类、状态迁移、错误猜测 |
| HTTP | 边界值、错误猜测 |
| UI | 场景法（鉴权落地后再补） |

- **P0**：每个入口的主成功 + 该入口会冒出的每个 `ErrorCode` 一条（按入口计，不是全局每种码一次）
- **P1**：过滤、分页、替换、闭环次要分支
- **P2**：畸形输入、协议边角

同类只留代表（如 `age` 17/18/150/151）。入口不同则契约不同，禁止「POST 测过 409 就跳过 PUT」。

## 覆盖清单

空单元格 = 缺口；无该模式填 `—`。一条 TC 可挂多条相近契约，清单须写全编号。

未落地能力不进分母。契约变更则重算。行覆盖不作验收标准。

```text
契约覆盖率 = 已挂接 TC 的契约条数 / 清单契约条数
```

**1. 入口 × 结果（P0）** — 每入口：主成功 + 实际会冒出的每个 `ErrorCode`

| 入口 | 主成功 | Schema 422 | 协议 400 | 业务失败 |
|------|--------|------------|----------|----------|
| | | | | |

**2. Schema × 等价类** — 合法 + 边界内/外（+ 默认、coerce、refine）

| 契约 | 代表 | TC |
|------|------|-----|
| | | |

**3. Service × 状态** — 每个 `throw` / 不变式一行

| 契约 | TC |
|------|-----|
| | |

**4. 场景（通常 P1）** — 至少一条：创建 → 列表 → 改 → 再查 → 删 → 再查 404

| 契约 | TC |
|------|-----|
| | |

矩阵无空格（`—` 除外）= 写全。
